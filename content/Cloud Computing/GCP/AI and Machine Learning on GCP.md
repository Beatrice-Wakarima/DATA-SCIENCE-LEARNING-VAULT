

## Defining AI and ML

- **Artificial Intelligence (AI)** → simulation of human intelligence in machines.
    
- **Machine Learning (ML)** → branch of AI where machines learn from data to make predictions/decisions.
    
- ML improves performance over time without explicit programming.
    

## Data Quality in ML

- ML algorithms train on data → quality is critical.
    
- “Garbage in, garbage out.”
    
- High-quality data is clean, comprehensive, relevant, and up-to-date.
    
- Poor data → inaccurate predictions and adverse impacts.
    

## GCP AI/ML Solutions

- Built on Google’s global infrastructure → low latency, reliability.
    
- Comprehensive suite of AI/ML services for all expertise levels.
    

## Pre-Trained Models

- **Vision AI** → image labeling, object detection, handwriting recognition.
    
- **Video AI** → place/object recognition, metadata extraction.
    
- **Natural Language AI** → text insights (topic extraction, sentiment analysis).
    
- Ready-to-use, cost-effective, easily integrated into applications.
    

## BigQuery ML

- Train basic ML models directly in BigQuery.
    
- Accessible to analytics users familiar with SQL.
    
- Seamless transition from data analysis → ML application.
    

## Vertex AI

- Integrated ML platform for building, training, and deploying models.
    
- **AutoML** → no-code ML, automated tuning, supports tabular, image, and text data.
    
- **Custom Training** → advanced control and flexibility for data scientists.
    
- Streamlines ML operations across GCP.
    

## Business Applications

- **Retail** → predict customer churn with BigQuery ML, deploy via Vertex AI.
    
- **Healthcare** → AutoML for medical imaging (e.g., disease vs. healthy).
    
- **Finance** → custom training for stock recommendation models tailored to customer profiles and trends.
