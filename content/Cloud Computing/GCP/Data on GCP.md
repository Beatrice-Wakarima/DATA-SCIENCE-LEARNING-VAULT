

## Data-Driven Culture

- Data is an invaluable asset across all sectors.
    
- A data-driven culture leverages data systematically to inform decisions.
    
- Enables objective, evidence-based strategies and operational efficiencies.
    
- GCP provides vast storage and real-time analysis capabilities, allowing organizations to pivot quickly, adapt to market changes, and optimize operations.
    

## Data Types

### Structured Data

- Relational, row-column format (tables, spreadsheets).
    
- Rigid schema, robust but less flexible.
    
- Difficult to scale.
    
- Stored in **Cloud SQL**.
    

### Unstructured Data

- Multimedia files and raw text (images, audio, video).
    
- Non-relational, lacks schema.
    
- Highly flexible and scalable.
    
- Stored in **Cloud Storage**.
    

### Semi-Structured Data

- Examples: organization trees, key-value pairs.
    
- Flexible, scalable, and fast.
    
- Ideal for big data without rigid schema (emails, social media posts, insurance claims, health records).
    
- Stored in **Bigtable**.
    

## Retail Use Case

- **Transactional data** → Cloud SQL for inventory and sales at global scale.
    
- **Customer profiles & social media posts** → Semi-structured data in Bigtable for product recommendations.
    
- **Multimedia files** → Cloud Storage for product images and promotional videos.
    
- Together, these services enhance operational efficiency and customer experience.
