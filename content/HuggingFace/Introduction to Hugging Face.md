## 🗂 Example: Finding the Right Model

**Scenario:**

- Task: text generation model for internal chatbot.
    
- Navigate Hub → filter by “Text Generation.”
    
- Browse latest, most downloaded, trending models.
    

## 🗂 Model Cards

**Contents:**

- Model name + uploader.
    
- Supported tasks + modalities.
    
- Languages + licensing info.
    
- Intended use + limitations.
    
- Training parameters + datasets.
    
- Evaluation results → compare models.
    
- Often includes linked research papers.
    

## 🗂 Testing and Running Models

**Options:**

- Run directly via Hub interface.
    
- Use **transformers** library for inference/training.
    
- Inference = prediction (e.g., text generation).
    
- Create notebooks with pre‑populated code.
    
- Serve with **vLLM** → fast, memory‑efficient deployment.
