

**Purpose:** Save time by knowing where everything lives.

- Home page is the landing spot.
    
- Left navigation menu moves between sections.
    

## 🗂 Key Sections

**Purpose:** Core areas of the portal.

- **Home** → Copilot, learning resources, quick links.
    
- **Create** → build new flows.
    
- **My flows** → manage existing flows.
    
- **Templates** → pre-built starting points.
    
- **Connectors** → browse available services.
    

## 🗂 Create Page

**Purpose:** Where flows begin.

- Start from blank.
    
- Pick from a template.
    
- Let a connector lead the way.
    
- Also lists Desktop flows & Business Process Flows (focus here: cloud flows).
    

## 🗂 My Flows

**Purpose:** Flow library.

- Shows name, last modified, type.
    
- Tabs: Cloud flows, Desktop flows, Shared with me.
    
- Click to open detail page.
    

## 🗂 Editing Flows

**Purpose:** Modify existing flows.

- Detail page toolbar: Edit, Run, Share, Save as copy, Delete, Export, Turn off.
    
- Details panel: creation date, last modified, type, run history.
    

## 🗂 Templates

**Purpose:** Pre-built starting points.

- Search for flows (e.g., email notifications, SharePoint approvals).
    
- Review triggers, actions, connections before using.
    
- Templates are starting points — may need cleanup (hardcoded values, outdated actions, missing error handling).
    

## 🗂 Connectors

**Purpose:** Toolbox of services.

- Over 1,000 services available.
    
- Covered in detail in Chapter Two.
    

## 🗂 Environments

**Purpose:** Separate flows, connections, and data.

- Environment switcher in top-right corner.
    
- Default environment for everyday work.
    
- Separate environments for dev/testing.
