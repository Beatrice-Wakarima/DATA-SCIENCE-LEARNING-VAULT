## 🗂 Licensing

**Purpose:** Access and connectors.

- User-based vs capacity-based licenses.
    
- Microsoft 365 → includes standard connectors.
    
- Premium connectors (Salesforce, Dataverse) → need Premium license.
    

## 🗂 Cloud Flow Types

**Purpose:** Flow categories.

- **Instant** → triggered by a person (button click).
    
- **Automated** → triggered by an event (email, file upload).
    
- **Scheduled** → triggered by time (daily, weekly, monthly).
    
- Quick rule: Person → Instant, Event → Automated, Clock → Scheduled.
    

## 🗂 Beyond Cloud Flows

**Purpose:** Other flow types.

- **Desktop flows** → automate local PC tasks (legacy apps).
    
- **Business Process Flows** → guide users through multi-stage processes with progress bars.
