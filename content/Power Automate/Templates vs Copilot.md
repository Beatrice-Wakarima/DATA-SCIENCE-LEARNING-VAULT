 

**Purpose:** Skip the blank canvas.

- Start from a template.
    
- Or edit existing flows with Copilot.
    
- Covers finding, auditing, editing, explaining, and undoing.
    

## 🗂 Find, Preview, Connect

**Purpose:** Use templates effectively.

- Search gallery by keyword or category.
    
- Preview → audit trigger, actions, connectors.
    
- Connect → sign in, click Continue, customize flow.
    
- Saved flows appear under **My flows**.
    

## 🗂 Audit Templates

**Purpose:** Ensure reliability.

- Look for hardcoded values → replace with dynamic.
    
- Check for deprecated actions.
    
- Add missing error handling.
    
- Confirm trigger type matches scenario.
    
- Templates are starting points, not finished products.
    

## 🗂 Flow Checker

**Purpose:** Validate flows.

- Designer toolbar → stethoscope icon.
    
- Runs checks for missing required fields.
    
- Pane lists errors and warnings.
    

## 🗂 Editing with Copilot

**Purpose:** Modify flows in plain language.

- Open Copilot sidebar from designer toolbar.
    
- Example: “Add a step to get my profile” → adds Office 365 Users action.
    
- Example: “Remove failure notification” → deletes step, rewires flow.
    
- Enter prompt in chat input.
    
- Be specific if multiple similar steps exist.
    
- Always review changes before proceeding.
    

## 🗂 Copilot Explain

**Purpose:** Understand flows.

- Ask “What does this flow do?” → plain‑English summary.
    
- Useful for auditing templates or shared flows.
    
- Can explain individual actions (e.g., trigger behavior).
    

## 🗂 Undo Safety Net

**Purpose:** Correct mistakes.

- Copilot may misinterpret intent or use outdated actions.
    
- After modification → review adjustments.
    
- If wrong, click **Undo** before sending new prompt.
    
- Once a new prompt is sent, previous change becomes final.
    
- You remain in control of finalized flow.
