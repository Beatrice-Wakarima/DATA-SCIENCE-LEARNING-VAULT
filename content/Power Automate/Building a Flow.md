

**Purpose:** Two main approaches.

- Build from scratch → pick each piece.
    
- Use Copilot → describe what you want.
    
- Always verify the flow ran successfully.
    

## 🗂 Create Page

**Purpose:** Starting point.

- Open **Create** from left navigation.
    
- Lists all flow types.
    
- Pick type that matches how flow should start.
    

## 🗂 Flow Type & Trigger

**Purpose:** Define how flow begins.

- Dialog opens → name the flow.
    
- Pick a trigger (e.g., _Manually trigger a flow_ for Instant).
    
- Click **Create** to open editor.
    

## 🗂 Adding Actions

**Purpose:** Build flow steps.

- Click **+** below trigger → action picker.
    
- Search bar to find actions.
    
- Example: **Compose** under Data Operation outputs text.
    

## 🗂 Reviewing Cards

**Purpose:** Inspect triggers/actions.

- Click card to open.
    
- Chevron collapses back to canvas.
    
- Don’t confuse with Back arrow (leaves flow).
    

## 🗂 Saving Flows

**Purpose:** Persist changes.

- No need to save between actions.
    
- Click **Save** in top bar once flow is complete.
    

## 🗂 Testing Flows

**Purpose:** Verify execution.

- Click **Test** → choose _Manually_.
    
- Run flow → look for green success banner.
    
- Each action card gets a check mark when successful.
    

## 🗂 Run History

**Purpose:** Debugging tool.

- Every run creates a record.
    
- Green check = success, Red X = failure.
    
- Inspect Outputs of failing step for cause.
    

## 🗂 Flow Runs Page

**Purpose:** Detailed run view.

- After success → Run flow panel shows link.
    
- Click to open run detail view.
    
- Expand steps to see Inputs & Outputs.
    
- Show raw outputs for exact text.
    

## 🗂 Copilot Entry Points

**Purpose:** Automate with natural language.

- Home page → “Create your automation with Copilot.”
    
- Create page → “Describe it to design it.”
    
- Both open same experience.
    

## 🗂 Writing Copilot Prompts

**Purpose:** Get useful drafts.

- Vague prompt → vague flow.
    
- Strong prompt → includes trigger, condition, action.
    
- Example: _When a new email arrives with “invoice” in subject, save attachment to SharePoint folder Incoming Invoices._
    

## 🗂 Copilot Drafts

**Purpose:** Treat outputs as suggestions.

- Always review trigger & actions.
    
- Confirm connectors & dynamic content.
    
- Read plain‑English summary in chat panel.
    
- Adjust before saving.
