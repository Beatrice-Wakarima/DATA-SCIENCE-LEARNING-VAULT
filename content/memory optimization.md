# 🧠 Memory Optimization Notes  
**Tags:** `#performance` `#types` `#bankmarketing`

## Downcast Targets
- Booleans → `int8`
- Small counts → `int8` or `int16`
- IDs → `int16` or `int32` depending on volume

## Benefits
- Reduces memory footprint
- Speeds up processing and export
- Prepares pipeline for cloud deployment
