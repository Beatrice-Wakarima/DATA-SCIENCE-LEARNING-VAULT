

**Purpose:** Entry point for building **Canvas Apps** in the Maker portal.

### 🔑 Steps to Begin

- Sign in with your **Microsoft 365 organizational account**.
    
- Navigate to **make.powerapps.com**.
    
- Explore the **left-hand menu**: Home, Create, Apps, Plans.
    
- Use **Copilot input** (top center) to describe app functionality in plain language.
    
- Note: Copilot apps run on **Dataverse**, which may require additional licensing.
    

### 🗂 Create Tab

Options to start:

- **Copilot** → AI-generated app scaffolds.
    
- **Connect to data** → Excel, SharePoint, SQL, etc.
    
- **Page design** → Prebuilt layouts.
    
- **Blank canvas** → Full control.
    

Additional features:

- **Do more with your apps** → Copilot agents, **Power Automate** flows, websites, AI Hub.
    
- **Templates** → Example apps (not recommended for production).
    

### 🗂 Navigation

- **Home** → Quick links, Copilot, learning resources.
    
- **Apps tab** → List of existing apps, buttons to create new ones.
    
- **Plans** → Describe business problems in plain language → Copilot generates apps, flows, tables.
    

### 🗂 Learning Resources

- “Learning for every level” section → Microsoft training, blogs, forums, how-to articles, videos.
    
- Accessible via **See all** link at bottom of Home page.
    

### 🗂 Data Source Setup

- Use **OneDrive** as a data source.
    
- Access via **app launcher (waffle icon)** → OneDrive.
    
- Upload Excel file with **+ Add new**.
    
- This file becomes the dataset for your first app.
    

### 🗂 Mobile Access

- Download **Power Apps Mobile** from app store.
    
- Sign in with Microsoft 365 credentials.
    
- Run any canvas app directly on your device.
