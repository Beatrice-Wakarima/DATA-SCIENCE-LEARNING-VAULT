

**Purpose:** Capture demo workflow for adding and customizing Q&A visuals in Power BI.

### 📌 Adding Q&A Visual

- Narrow inspections chart → free space on Overview page.
    
- Add **Q&A Visual** → starts with suggestions + query box.
    
- Example query: “Number of inspections by date.”
    
- Ambiguity resolved → chose **inspection date**.
    
- Refined to **year + month** for readability.
    
- Changed visual type using “as” → column chart.
    

### 📌 Converting Visuals

- Q&A visual can be converted to **standard visuals** for fine‑grained tuning.
    
- Conversion allows direct editing of axes, legends, formatting.
    

### 📌 Synonyms Setup

- Field synonyms → define alternative terms.
    
- Example:
    
    - Food Inspections → add synonym “examination.”
        
    - Score → add synonym “rating.”
        
- Synonyms improve query flexibility.
    

### 📌 Teach Q&A

- Define business jargon terms.
    
- Example query: “Dirtiest inspections in Cary.”
    
    - Cary recognized as city.
        
    - “Dirtiest” interpreted as **low scores**.
        
- Adjust query → show by inspection key for clarity.
    
- Save changes for reuse.
    

### 📌 Example Queries

- “Average rating by city” → scores 95–99.
    
- Clayton lowest → drill into “dirtiest inspections in Clayton.”
    
- Result: table with inspection details (e.g., grocery & grill, score 84).
    
- Drillthrough → inspection report with comments, inspector name, date, score.
    

### 📌 UI Trick: Left‑Aligned Card

- Cards only center‑alignable.
    
- Workaround: use **button text** formatted by column (inspector name).
    
- Since one inspector per inspection, first inspector suffices.
