

**Purpose:** Capture how to use the Q&A visual to give users control over queries and visuals.

### 📌 Q&A Capabilities

- **Q&A Visual** → Users input questions as queries.
    
- Works in English (other languages coming).
    
- Features: auto‑complete, spell‑check, preview answers.
    
- Limitations: highlights unknown words, language constraints.
    

### 📌 How It Works

- Enter column/measure names directly.
    
- Use prepositions (e.g., “by”) → all behave the same.
    
- Example: “Actual amount by cost center by date.”
    
- Uses **Natural Language Processing** to interpret queries.
    
- Chooses most appropriate visual automatically.
    

### 📌 Requesting Specific Visuals

- Can specify visual type: table, treemap, ribbon chart.
    
- Limited control → Q&A decides axis vs legend.
    
- Complex queries may need conversion to actual visuals for fine‑tuning.
    
- **Convert Q&A Visual** → allows direct editing.
    

### 📌 Synonyms

- **Synonyms** → multiple words for same column.
    
- Auto‑suggested + custom names.
    
- Avoid duplicate synonyms across columns → causes ambiguity.
    

### 📌 Teach Q&A

- Define custom terms:
    
    - **Nouns** → specific fields, filters.
        
    - **Adjectives** → filters (e.g., “high risk”).
        
- Supports business jargon.
    
- Verbs not supported (e.g., “allocated”).
    

### 📌 Making Q&A Work Better

- Name columns/measures clearly in natural language.
    
- Avoid cryptic symbols.
    
- Provide synonyms + terms for business units.
    
- Offer **sample questions** to guide users.
    

### 🔗 Connections

- Links to **Bookmarks & Navigation** for storytelling.
    
- Connects with **Conditional Formatting** for clarity in visuals.
    
- Bridges into **End Goal of the Course** → Q&A as storytelling tool.
