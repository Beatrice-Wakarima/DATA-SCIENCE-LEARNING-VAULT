

**Purpose:** Capture methods for enhancing navigation in Power BI reports.

### 📌 Navigation & Stories

- **Structured Navigation** → Helps tell data stories effectively.
    
- Dashboards: structure via layout of visuals.
    
- Reports: structure via navigation (pages, flows).
    
- Benefits: starting point → concepts → deeper exploration.
    

### 📌 Bookmarks

- **Bookmarks** → Capture predefined states.
    
- Similar to browser bookmarks but retain state.
    
- Can save:
    
    - Page location.
        
    - Filters & slicers.
        
    - Selected visuals for cross-filtering.
        
    - Sort order.
        
    - Drillthrough location.
        
    - Visibility of objects (hide/show elements).
        

### 📌 Bookmark Navigator

- Access via **View ribbon**.
    
- Features:
    
    - Add, select, modify, remove bookmarks.
        
    - Group bookmarks logically.
        
    - View bookmarks as slideshow.
        
- **Bookmark Navigator** → Simplifies managing multiple bookmarks.
    

### 📌 Buttons

- **Buttons** → Perform actions on pages.
    
- Examples:
    
    - Auto back button (drillthrough).
        
    - Drillthrough via button (instead of right-click).
        
    - Navigate to other pages (table of contents).
        
    - Select bookmarks.
        
    - Link to external URLs (source data, explanations).
        

### 📌 Navigator Feature

- **Navigator** → Built-in navigation tool.
    
- Automates navigation creation.
    
- Customizable visibility in format pane.
    
- **Page Navigator**:
    
    - Syncs with report pages.
        
    - Titles match page names.
        
    - Order defined by user.
        
    - Selected button highlights current page.
        
    - Auto-updates with report changes.
