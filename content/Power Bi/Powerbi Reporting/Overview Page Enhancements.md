

**Purpose:** Capture techniques for formatting buttons, tooltips, icons, and interactions on the Overview page.

### 📌 Button Formatting

- **Button States** → Customize Disabled, Hover, Default.
    
- Disabled state: icon → blank shape, text → “Select an Inspection Report.”
    
- Hover state: border weight → 3px (default = 0px).
    
- Adds emphasis when hovering over buttons.
    

### 📌 Tooltip Pages

- Create hidden pages for tooltips:
    
    - **Inspections over Time** → Line chart (Date vs. Number of inspections, expanded to quarter).
        
    - **Summary of Issues** → Table (Category vs. Number of violations).
        
- Hide pages via **right-click → Hide Page**.
    
- Format menu: enable Tooltip, set Page size → “Tooltip.”
    

### 📌 Using Tooltips

- On Overview page:
    
    - Table visual → Tooltip = “Summary of Issues.”
        
    - Hover → shows violations table for inspection.
        
- Visual header tooltip:
    
    - Enable “Help tooltip” in Header Icons.
        
    - Set tooltip page → “Inspections over Time.”
        
    - Hover over question mark → shows line chart.
        

### 📌 Unicode Icons & Emoji

- Add column **Facility Type Display** with icons:
    
    - Salt shaker → restaurants.
        
    - Truck → food trucks.
        
    - School → lunchrooms.
        
- Rename column → “Type.”
    
- Compact storytelling with icons.
    

### 📌 Conditional Formatting

- Violations column → Data bars (show bar only).
    
- Score column → Icons (adjust thresholds since scores rarely <90).
    
- Enhances readability and visual appeal.
    

### 📌 Edit Interactions

- Format menu → “Edit interactions.”
    
- Control how table selections affect visuals.
    
- Example: bar chart → switch from highlight (default) to filter.
    
- Close interactions when done.
