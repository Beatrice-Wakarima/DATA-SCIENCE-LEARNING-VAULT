### 01

### Open Bookmarks Pane

Access the bookmarks pane to begin creating navigation states.

Go to **View ribbon → Bookmarks pane**

- Click **Add** to create a new bookmark
    
- Rename via ellipsis → e.g., _Overview_
    
- Tracks current page, filters, and display options
    

### 02

### Create Drillthrough Bookmark

Add a bookmark after drilling into a restaurant report.

- Right-click restaurant → **Drill through → Inspection Report**
    
- Add a card with restaurant name
    
- Format → turn off category label
    
- Create new bookmark → _Restaurant_
    

### 03

### Add Filtered Bookmark

Capture a filtered state for specific inspector and date.

- Return to Overview page
    
- Select inspector _Lauren Harden_
    
- Adjust scatter chart to 201904
    
- Add bookmark → _Lauren 2019_
    

### 04

### Use Bookmark Navigator

View and navigate bookmarks sequentially.

On Bookmarks pane → **View**

- Navigate with arrow indicators
    
- Interact with report elements while browsing
    
- Note: Play axis cannot be primed via bookmark
    

### 05

### Insert Navigation Buttons

Add buttons for drillthrough and bookmarks.

Go to **Insert → Buttons**

- Choose icon (e.g., right arrow)
    
- Format → Style → toggle text → add label
    
- Action → enable → select _Drill through → Inspection Report_
    
- Requires restaurant selection to enable
    

### 06

### Add Bookmark Button

Provide direct access to a saved bookmark.

- Insert new button under drillthrough button
    
- Label → _Lauren_
    
- Action → Bookmark → select _Lauren 2019_
    
- Control-click to navigate to saved state
    

### 07

### Use Page Navigator

Enable built-in navigation across report pages.

Go to **Insert → Buttons → Navigator → Page Navigator**

- Auto-creates navigation list of report pages
    
- Titles sync with page names
    
- Order defined by user
    
- Highlights current page automatically
